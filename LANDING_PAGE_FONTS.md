# Landing Page — Complete Text & Font Style Reference

> Every visible text element on the landing page, with its exact font style.

## Global Font Scope

The entire landing page is wrapped in `.landing-fonts`, which sets:

```
Default font: Space Grotesk, system-ui, sans-serif
```

Any element with an inline `style` containing "Playfair" is excluded from this override and uses Playfair Display.
